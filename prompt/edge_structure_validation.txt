TASK

Validate the structure of EDGE_CANDIDATE_EXTRACTION_OUTPUT.
Do not create the final normalized edge set in this step.
Your job is to identify shortcut edges, missing local links, unsupported candidate edges,
and relation normalization guidance needed for the final edge output.

VALIDATION RULES

VALIDATION BASIS

  1. Use CAUSAL_NARRATIVE_EXTRACTION as the primary reference for the intended accident
     progression.
  2. Use INCIDENT_DESCRIPTION as the primary factual source for checking whether candidate
     edges and missing local links are directly supported.
  3. Use EDGE_CANDIDATE_EVIDENCE_SNIPPETS only as supporting evidence anchors, not as the
     only basis for validation.
  3a. Use CAUSAL_EDGE_SCHEMA_DEFINITION as the authoritative guide for relation meaning
      and allowed edge patterns.
  3b. Use CAUSAL_EDGE_ISSUE_DEFINITION as the authoritative guide for edge-related issue
      meanings.
  3c. Use CAUSAL_ISSUE_OUTPUT_DEFINITION as the authoritative guide for shared
      validation-style output structure.
  3d. Evaluate edge problems in this order:
      (1) missing_local_link and other required local connectivity gaps,
      (2) wrong_relation,
      (3) unsupported_edge,
      (4) shortcut_edge.
      Diagnose shortcut_edge only after first determining that the necessary
      supported local edge structure is already present.

ISSUE DEFINITIONS

  4. Use shortcut_edge, missing_local_link, wrong_relation, and unsupported_edge
     only in ways consistent with CAUSAL_EDGE_ISSUE_DEFINITION.
  5. Apply the allowed and disallowed relation patterns defined in
     CAUSAL_EDGE_SCHEMA_DEFINITION when judging wrong_relation or unsupported_edge.
  6. Use other only for a material structural edge problem that does not fit the categories
      above.

STRUCTURAL CHECKS

  7. Check the candidate edge set against the definitions above and report the validation
      results using the defined issue types.
  7a. If a retained Condition node carries supported state semantics but is not connected
      to the retained Event, Entity, or mechanism stage that it should characterize or
      locally enable, prefer diagnosing missing_local_link rather than leaving the
      retained Condition disconnected.
SCOPE LIMIT

  8. Do not recommend adding brand-new nodes in this step.
  9. Do not recommend purely stylistic changes.

OUTPUT REQUIREMENTS

Return one JSON object using the exact `edge_structure_validation`
output structure defined in CAUSAL_ISSUE_OUTPUT_DEFINITION.

OUTPUT FORMAT

Return JSON only.
Do not include explanations or additional text outside the JSON object.
