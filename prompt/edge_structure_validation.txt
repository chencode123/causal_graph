TASK

Validate the structure of EDGE_CANDIDATE_EXTRACTION_OUTPUT.
Do not create the final normalized edge set in this step.
Your job is to identify shortcut edges, missing local links, weak or unsupported candidate edges, and relation normalization guidance needed for the final edge output.

VALIDATION RULES

  1. Use CAUSAL_NARRATIVE_EXTRACTION as the primary reference for the intended accident
     progression.
  2. Use EDGE_CANDIDATE_EVIDENCE_SNIPPETS only as supporting evidence anchors.
  3. Treat a candidate edge as a shortcut if it bypasses a necessary or strongly supported
     intermediate local mechanism.
  4. If there is already a supported local chain A -> B -> C, then a direct edge A -> C must
     be treated as a shortcut/transitive edge and should be removed.
  5. Treat a local link as missing if the narrative clearly supports a direct local
     mechanism between existing node semantics and the candidate edge set does not represent
     it.
  6. Prefer marking missing or weak edges only when the relevant node semantics already
     exist in IDENTIFY_ACCIDENT_SCENARIO_OUTPUT.
  7. Do not recommend adding brand-new nodes in this step.
  8. Do not recommend purely stylistic changes.
